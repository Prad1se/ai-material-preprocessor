# AI Material Preprocessor 2.0.0

> Turn documents and videos into clean, AI-ready materials — locally on your Windows PC.

AI Material Preprocessor 2.0.0 is the first stable release of a local Windows desktop tool that
turns documents and videos into clean, AI-ready materials: documents become readable, traceable
Markdown packages; video becomes standardized, named, deduplicated creative assets. Everything runs
on your machine, and source files are never overwritten.

## Highlights

### 1. Stable 2.0 release

The capabilities validated in the 2.0.0rc1 pre-release are now a stable release: reliable batch
processing, document previews and quality reports, provenance-tracked AI packages, video material
management, first-run onboarding, themes, and the reproducible Windows build pipeline.

### 2. Easier tool setup

Missing capabilities can be restored from the application without leaving it:

- supplement ExifTool / LibreOffice / FFmpeg after explicit confirmation in first-run or Settings;
- ExifTool downloads are pinned to an official version with a fixed SHA-256 and safe extraction;
- LibreOffice and FFmpeg are installed through WinGet with exact package identifiers;
- the managed tool directory is configurable (for example a spacious D: drive);
- capabilities are re-detected and resolved executable paths are saved after installation.

### 3. AI-ready document packages

Documents (PDF, Word, PowerPoint, Excel, HTML, and more) become Markdown packages with automatic
cleaning, structure-aware chunks, source traceability to pages/slides/worksheets, a compact
manifest, and optional local OCR. This is preparation for AI consumption, not a replacement for the
AI itself.

### 4. Video material preparation

Raw video can be compressed, standardized to MP4, named by capture time/location/device metadata,
deduplicated, and organized with keyframe contact sheets. This is asset preparation — not AI video
understanding, captioning, or editing.

### 5. Local-first and safe

Processing, cleaning, OCR, metadata reading, and history all stay on your computer by default. No
files are uploaded by default; source files are never deleted or overwritten; network operations
(such as update checks or tool downloads) require explicit confirmation; processing history does
not store document body content.

## Download

- **Portable** — `AI-Material-Preprocessor-v2.0.0-windows-x64.zip`: extract the whole archive and
  run `AI-Material-Preprocessor.exe`. Choose this if you prefer not to install anything.
- **Installer** — `AI-Material-Preprocessor-v2.0.0-windows-x64-setup.exe`: installs for the current
  user with an uninstall entry. Choose this for a normal Windows install/uninstall experience.

`SHA256SUMS.txt` verifies the integrity of every download.

`FFmpeg-8.1.2-source-38b88335f9.zip` is the corresponding GPLv3 source archive published to satisfy
the FFmpeg license obligations; it is not a program you need to run.

## Known Limitations

- Windows x64 only.
- Local OCR is off by default and must be enabled in Settings; complex diagrams and equations still
  need a human or a vision-capable model.
- Word/PowerPoint → PDF conversion depends on Microsoft Office or LibreOffice on the machine.
- Video features prepare material; they do not understand, caption, or edit video content.
- The application does not bundle RAG, search, or an agent runtime — it prepares input for your own
  AI workflow.
- Markdown cannot fully reconstruct complex visual layouts (SmartArt, formulas, chart spatial
  relations); quality reports keep risk warnings for these cases.
- The current release is not commercially code-signed, so Windows SmartScreen may warn; verify the
  SHA-256 checksum before continuing.

See [docs/TROUBLESHOOTING.md](../TROUBLESHOOTING.md) for common issues.

## Upgrade Notes

No known breaking configuration change for 2.0.0rc1 users. User configuration remains at
`%LOCALAPPDATA%\AI Material Preprocessor\config.json` with versioned, backward-compatible migration;
the new managed-tool directory field defaults to a safe value. Processing history remains
compatible.

## Privacy

Files stay local. Update checking is off by default and runs only after explicit consent and a
manual action. Tool supplementation shows source, version, license, and destination before any
network access.
