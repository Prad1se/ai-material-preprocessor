# AI Material Preprocessor 2.0 RC1

This release candidate turns the prototype into a maintainable Windows local application for AI
document preparation and creative media organization.

Highlights:

- persistent multi-file task queue with cancellation, retry, recovery, disk checks, and history;
- document/video previews and application-only quality reports;
- enhanced Markdown cleanup, structural chunking, OCR provenance, and compact AI-package manifests;
- offline video metadata, naming previews, duplicate detection, organization, keyframes, contact
  sheets, compression, audio extraction, and MP4 standardization;
- first-run mouse welcome, graphical settings, capability/version detection, themes, folder drop,
  and high-DPI support;
- portable ZIP, current-user installer, SHA-256 checksums, reproducible scripts, and clean Windows
  GitHub Actions validation.

Release validation extracts the published portable ZIP and runs both its self-test and GUI smoke
check. The installer is silently installed for the current user, tested from the installed path,
and uninstalled again. Build-only NSIS and 7-Zip bootstrap files are hash-pinned and are not shipped
inside the product.

Validation completed with 200 passing tests plus one opt-in Office environment test. The portable
ZIP was independently rebuilt with the same SHA-256, and both the extracted portable application
and the full installer lifecycle passed self-test and GUI startup checks. Exact artifact hashes are
listed in SHA256SUMS.txt.

Privacy: files stay local. Update checking is off by default and runs only after explicit consent
and a manual action. This RC is not commercially code-signed, so Windows SmartScreen may warn.
