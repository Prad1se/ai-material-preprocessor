# Security Policy

## Supported version

Security fixes are applied to the latest published release.

## Reporting a vulnerability

Please report vulnerabilities through GitHub private vulnerability reporting instead of opening a public issue. Include the affected version, reproduction steps, expected impact, and any suggested mitigation.

## Local processing boundary

The application processes files locally and does not upload source material. Document conversion runs with the permissions of the current Windows user, so only process files from sources you trust. Conversion output, task history, and extracted metadata can contain sensitive content or local file paths; review them before sharing.
