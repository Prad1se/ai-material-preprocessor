# Research Paper Example

Demonstrates **PDF page-level provenance**.

- Input: `input/sample-paper.pdf` — a tiny synthetic, text-based 2-page PDF (not a real paper).
- Output: `sample-context-pack/` — a real AI Context Pack generated by the app.

Open the pack, then in the app use **View Source Map** to see blocks mapped to *PDF page 1* and *PDF page 2*. The Context Report shows token estimates, budget status, warnings, and integrity.
