# Course Material Example

Demonstrates **document-level fallback provenance**.

- Input: `input/sample-lecture.docx` — a tiny synthetic DOCX (not real course material).
- Output: `sample-context-pack/` — a real AI Context Pack generated by the app.

DOCX has no reliable page markers in the current pipeline, so the Source Map shows *Document-level fallback* instead of a fabricated page number. The pack itself is fully usable: read `START_HERE.md`, then **Copy for AI** from the app.
